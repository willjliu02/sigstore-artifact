# Security Policy

## Supported Versions
Security fixes will be provided on the `main` branch.

## Reporting Vulnerabilities
Report suspected vulnerabilities privately to wjl9629@nyu.edu
Include reproduction steps, affected versions, and potential impact.

Please avoid disclosing vulnerabilities details in the public issue until 14 days after the initial
communication.

## Security Updates
Confirmed vulnerabilities will be released on `main`.
Security fixes and any required upgrades will be documented in the release notes.
